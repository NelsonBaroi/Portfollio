ডেটা অ্যানালিটিক্স শেখার পরিকল্পনা

(দিনে ১ ঘন্টা, সপ্তাহে ৫ দিন)

এটি শেখার পরিকল্পনা, সম্পন্ন যোগ্যতার তালিকা নয়।

১-৩ মাস: মৌলিক ডেটা অ্যানালিটিক্স দক্ষতা (ভিত্তি)

ফোকাস: পাইথন, এসকিউএল, এক্সেল, পাওয়ার বিআই/ট্যাবলু

১-২ সপ্তাহ: পাইথন বেসিক

  • Topics: বিষয়: ভেরিয়েবল, ডেটা টাইপ, লুপ, ফাংশন, শর্তাধীন বিবৃতি
  • Resources:
    • Python for Everybody - University of Michigan (Coursera - Free/Paid)
    • Python Basics - Coursera Project Network (Free)

৩-৪ সপ্তাহ: ডেটা বিশ্লেষণের জন্য পাণ্ডাস ও নমপাই

  • Topics: বিষয়: ডেটাফ্রেম, সিরিজ, ইনডেক্সিং, ফিল্টারিং, গ্রুপিং, নমপাই অ্যারে
  • Resources:
    • Data Analysis with Python - IBM (Coursera - Free/Paid)
    • Python Data Science - University of Michigan (Coursera - Free/Paid)

৫-৬ সপ্তাহ: ডেটা অ্যানালিটিক্সের জন্য এসকিউএল

  • Topics: বিষয়: কোয়েরি, জয়েন, অ্যাগ্রিগেশন, সাবকোয়েরি, উইন্ডো ফাংশন
  • Resources:
    • SQL for Data Science - University of California, Davis (Coursera - Free/Paid)
    • Databases and SQL for Data Science - IBM (Coursera - Free/Paid)

৭-৮ সপ্তাহ: পাওয়ার বিআই ও ট্যাবলু

  • Topics: বিষয়: ডেটা ভিজুয়ালাইজেশন, ড্যাশবোর্ড, DAX, পাওয়ার কোয়েরি

৪-৬ মাস: উন্নত ডেটা অ্যানালিটিক্স ও বিজনেস ইন্টেলিজেন্স

ফোকাস: পরিসংখ্যান, ইটিএল, বিজনেস ইন্টেলিজেন্স, কেপিআই বিশ্লেষণ

৯-১০ সপ্তাহ: ডেটা অ্যানালিটিক্সের জন্য পরিসংখ্যান

  • Tasks: কাজ: কেপিআই ড্যাশবোর্ড বাস্তবায়ন, এসকিউএল-ভিত্তিক রিপোর্টিং প্রকল্প
