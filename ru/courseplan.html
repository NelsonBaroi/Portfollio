ENRUBN

План изучения аналитики данных

(1 час в день, 5 дней в неделю)

План обучения, а не полученные квалификации.

Месяцы 1-3: Базовые навыки анализа данных (Основа)

Фокус: Python, SQL, Excel, Power BI/Tableau

Недели 1-2: Основы Python

  • Topics: Темы: Переменные, типы данных, циклы, функции, условные операторы
  • Resources:
    • Python for Everybody - University of Michigan (Coursera - Free/Paid)
    • Python Basics - Coursera Project Network (Free)

Недели 3-4: Pandas и NumPy для анализа данных

  • Topics: Темы: DataFrame, series, индексация, фильтрация, группировка, массивы NumPy
  • Resources:
    • Data Analysis with Python - IBM (Coursera - Free/Paid)
    • Python Data Science - University of Michigan (Coursera - Free/Paid)

Недели 5-6: SQL для анализа данных

  • Topics: Темы: Запросы, объединения, агрегации, подзапросы, оконные функции
  • Resources:
    • SQL for Data Science - University of California, Davis (Coursera - Free/Paid)
    • Databases and SQL for Data Science - IBM (Coursera - Free/Paid)

Недели 7-8: Power BI и Tableau

  • Topics: Темы: Визуализация данных, дашборды, DAX, Power Query
  • Resources:
    • Data Visualization with Tableau - University of California, Davis (Coursera - Free/Paid)
    • Business Intelligence with Power BI - Coursera Project Network (Free)

Месяцы 4-6: Продвинутый анализ данных и бизнес-аналитика

Фокус: Статистика, ETL, бизнес-аналитика, анализ KPI

Недели 9-10: Статистика для анализа данных

  • Topics: Темы: Описательная статистика, вероятность, проверка гипотез
  • Resources:
    • Statistics for Data Science - Johns Hopkins University (Coursera - Free/Paid)
    • Business Statistics and Analysis - Rice University (Coursera - Free/Paid)

Недели 11-12: ETL и конвейеры данных

  • Topics: Темы: Очистка данных, трансформация, основы Apache Airflow
  • Resources:
    • Data Engineering Foundations - IBM (Coursera - Free/Paid)
    • Building ETL Pipelines with SQL and Python - Coursera Project Network (Free)

Недели 13-14: Бизнес-аналитика и анализ KPI

  • Topics: Темы: Бизнес-метрики, отслеживание KPI, принятие решений на основе данных
  • Resources:
    • Business Analytics - University of Pennsylvania (Coursera - Free/Paid)
    • Data-Driven Decision Making - PwC (Coursera - Free/Paid)

Недели 15-16: Практические кейсы и реальные проекты

  • Tasks: Задачи: Реализация KPI-дашбордов, проекты отчётности на SQL
  • Resources:
    • Capstone Project in Data Science - Coursera (Part of multiple Specializations)
    • Data Science Professional Certificate Projects - Coursera (IBM, Google)

Месяцы 7-9: Машинное обучение и облачная аналитика

Фокус: Основы ML, Big Data, облачные инструменты

Недели 17-18: Основы машинного обучения

  • Topics: Темы: Регрессия, классификация, кластеризация, разработка признаков
  • Resources:
    • Machine Learning - Stanford University (Coursera - Free/Paid)
    • Supervised Machine Learning - DeepLearning.AI (Coursera - Free/Paid)

Недели 19-20: Основы TensorFlow и PyTorch

  • Topics: Темы: Нейронные сети, модели глубокого обучения
  • Resources:
    • Deep Learning Specialization - DeepLearning.AI (Coursera - Free/Paid)
    • PyTorch for Deep Learning - Coursera Project Network (Free)

Недели 21-22: Инструменты Big Data (Hadoop, Spark)

  • Topics: Темы: Распределённые вычисления, аналитика в реальном времени
  • Resources:
    • Big Data Specialization - University of California, San Diego (Coursera - Free/Paid)
    • Introduction to Apache Spark - Coursera Project Network (Free)

Недели 23-24: Облачная аналитика (AWS, Google Cloud, Azure)

  • Topics: Темы: Облачная обработка данных, бессерверная аналитика
  • Resources:
    • Google Data Engineering Specialization - Google Cloud (Coursera - Free/Paid)
    • AWS Fundamentals - Amazon Web Services (Coursera - Free/Paid)

Месяцы 10-12: Специализация и реальные проекты

Фокус: Знание бизнес-доменов, консалтинг, создание портфолио

Недели 25-26: Финансовая аналитика и управление рисками

  • Topics: Темы: Прогнозирование, моделирование рисков, симуляции Монте-Карло
  • Resources:
    • Financial Engineering & Risk Management - Columbia University (Coursera - Free/Paid)
    • Risk Analytics and Management - University of Washington (Coursera - Free/Paid)

Недели 27-28: Маркетинговая аналитика и аналитика цепочек поставок

  • Topics: Темы: Сегментация клиентов, прогнозирование спроса
  • Resources:
    • Marketing Analytics - University of Virginia (Coursera - Free/Paid)
    • Supply Chain Analytics - Rutgers University (Coursera - Free/Paid)

Недели 29-30: IT/Data консалтинг и принятие решений

  • Topics: Темы: Коммуникация с заинтересованными сторонами, анализ кейсов
  • Resources:
    • Data Science for Business - University of Illinois (Coursera - Free/Paid)
    • Consulting Foundations - Coursera Project Network (Free)

Недели 31-32: Проекты для портфолио и подготовка к работе

  • Tasks: Задачи: Создать 3-5 проектов, оптимизировать LinkedIn и GitHub
  • Resources:
    • Applied Data Science Capstone - IBM (Coursera - Free/Paid)
    • Interview Prep - Coursera Project Network (Free)
