AI Memory

Локальная база знаний с индексацией файлов и интерактивным Q&A

Над чем работал

  • Мониторинг файлов в реальном времени с автоматической индексацией новых и изменённых файлов
  • Семантический поиск на основе эмбеддингов по индексированной базе знаний
  • Q&A на основе LLM, отвечающее на вопросы из найденного контекста
  • Настройка порога для определения момента запуска поиска вместо использования общих знаний

Stack

Python Embeddings Watchdog LLM Q&A
Что я узнал Более интересная проблема заключалась не в индексации, а в определении того, когда результат поиска достаточно релевантен для использования. Генерация с дополнением поиска настолько же хороша, насколько хорош фильтр релевантности перед ней; без него модель уверенно отвечает из неверного документа.

Qwen Voice Cloner

Многоязычное клонирование голоса с использованием Qwen3-TTS

Над чем работал

  • Конвейер клонирования голоса: загрузите образец, получите синтезированную речь
  • Дизайн голоса по текстовым описаниям («тёплый, спокойный, с лёгким акцентом»)
  • Встроенная библиотека дикторов и управление образцами голоса
  • Оптимизация CUDA / bfloat16 для GPU-инференса; запасной вариант на CPU
  • Поддержка 10 языков: английский, русский, китайский, японский, корейский и другие

Stack

Python PyTorch Qwen3-TTS Gradio SoundFile Librosa
Что я узнал Мелкие ошибки в выравнивании транскриптов — обрезанное слово, неверно интерпретированная пауза — превращаются в заметные артефакты на выходе. Конвейер предобработки важен не меньше самой модели. Я также обнаружил, что дизайн голоса по текстовым описаниям контролировать сложнее, чем клонирование с реального образца; интерпретация моделью слова «тёплый» варьируется.

Hairstyle Try-On

Редактирование причёсок на базе ИИ с использованием FLUX и Qwen облачных моделей

Над чем работал

  • Загрузка изображений, обнаружение лиц и конвейер предобработки
  • Двухдвигательная архитектура: FLUX как основной, Qwen как автоматический запасной
  • Более 15 цветов волос с собственным hex-пикером
  • Каталоги стилей по полу; история генераций для сравнения
  • Многоязычный интерфейс (английский и русский)

Stack

Python Streamlit Pillow OpenCV FLUX API Qwen API
Что я узнал Проектирование с учётом ненадёжности модели было главной инженерной задачей. Облачные API периодически дают сбой, и если приложение не обрабатывает это корректно, пользователь видит ошибку вместо результата. Создание запасного пути на уровне UI — так, чтобы переключение с FLUX на Qwen было незаметным — сделало интерфейс стабильным, даже когда отдельные вызовы таковыми не были.
Live Demo · GitHub

Parallel Universe Me

Симуляция жизни с использованием методов Монте-Карло и реальных статистических данных

Над чем работал

  • Движок симуляции Монте-Карло для вероятностного моделирования жизненных путей
  • Причинные DAG-диаграммы, отображающие деревья решений с весами статистических исходов
  • Сбор данных из BLS, OECD, Всемирного банка и исследований Кауффмана
  • LLM-рассказчик, интерпретирующий результаты симуляции — без генерации чисел
  • Фронтенд на Gradio с визуализациями Plotly; бессерверное развёртывание на Vercel

Stack

Python Gradio Plotly Pandas Monte Carlo Vercel
Что я узнал Исключение LLM из генерации данных было осознанным ограничением — и правильным. Как только модель начинает генерировать статистику, пользователи не могут отличить её от реальной, что подрывает всю суть. Роль LLM здесь — нарративная: она объясняет, что означает результат Монте-Карло. Числа берутся из реальных наборов данных. Архитектурно поддерживать такое разделение сложнее, чем кажется.
Live Demo · GitHub

SFX Generator

Процедурные звуковые эффекты из обработки сигналов — без использования сэмплов

Над чем работал

  • Более 18 типов звуковых эффектов: удары, свипы, дроны, глитчи, эмбиент-текстуры, сигналы
  • Фильтры Баттерворта, амплитудные огибающие, LFO-модуляция с нуля
  • Регулируемая длительность, частота, интенсивность и стереопанорамирование для каждого эффекта
  • Пакетный режим генерации; экспорт WAV с частотой 44,1 кГц, 16-битное стерео
  • Десктопный GUI на Tkinter для интерактивной работы

Stack

Python NumPy SciPy SoundFile Tkinter
Что я узнал Этот проект не использует модели ИИ — всё основано на обработке сигналов. Это оказалось полезным упражнением: проектирование звуков из частотных кривых и форм фильтров требует понимания того, что вы хотите получить от аудио, вместо описания на естественном языке с надеждой, что модель интерпретирует это правильно. Процедурная генерация даёт полный контроль ценой необходимости знать, что именно вы контролируете.

Kira

Структурированная личная база знаний для инъекции контекста LLM

Над чем работал

  • Организовал 19-главную биографию, материалы по карьере и планированию переезда
  • Аналитика визовых очередей: Python-скрипты, еженедельные CSV-наборы данных, 13 статистических графиков
  • Машиночитаемый manifest.json, индексирующий все файлы по категориям и форматам
  • Экспортировал и структурировал историю ИИ-диалогов за 6 месяцев
  • Предусмотрено повторное использование: любой файл можно подать как контекст любому LLM-инструменту

Stack

Python Markdown JSON HTML
Что я узнал База знаний полезна только тогда, когда вы можете найти нужную информацию в нужное время. Manifest.json — структурированный индекс каждого файла с метаданными — стал деталью, которая заставила всё работать. Без него репозиторий — просто папка документов. С ним любой инструмент может ориентироваться в содержимом, не читая всё подряд. Настоящая задача заключалась в определении того, что должно быть в базе знаний, а что — в разговоре.
github.com/NelsonBaroi/Kira
